# Student Performance Dashboard 📊

A Flask-based web application that analyzes student performance data and displays key academic insights using a Kaggle dataset.

---

## 🚀 Project Overview

This project reads student performance data from a CSV file and shows:
- Average hours studied
- Average attendance
- Average previous scores

The data is visualized on a simple dashboard built using **Flask** and **HTML templates**.

---

## 🛠️ Tech Stack

- Python
- Flask
- Pandas
- HTML / CSS
